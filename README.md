## プロジェクト概要
33年間の物流・現場キャリアで培った「最適化の知恵」と、Pythonという「拡声器」を融合させ、ベーカリー現場の売上管理を自動化・効率化するWebシステムを構築しました。

## 開発思想：C案の精神
強引に突っ込むのではなく、周囲（システム・環境）と調和し、安全に最短で目的地へ達する。
現場で培った「物流ルート最適化ロジック」をプログラミングへ応用し、複雑な業務フローをシンプルかつ頑丈な骨格へと落とし込みました。

## プロジェクト実績 (Project Metrics)
* **総投下時間:** 71時間
    * 基礎学習、環境構築、ドキュメント整備、発信活動など、プロジェクト全体の総時間です。
* **主要アプリ開発・実践履歴（時系列）:**
    1. **ニューススクレイピング・AI要約アプリ:** 21時間（初期の基盤構築・検証）
    2. **Puoppo (RSS最適化アプリ):** 10時間（1日間で集中構築）
    3. **ベーカリー売上高集計システム:** 15時間（約3日間で集中構築）
* **備考:** プロジェクトの残りの時間は、開発環境の最適化や運用のための発信活動等、エンジニアとして「現場で使える仕組み」を磨き上げるために充てました。

## 主な技術スタック
* **Backend:** Python, Flask (ルーティング, GET/POST, Jinja2)
* **Database:** SQLite3 (CRUD機能)
* **Automation:** openpyxl (Excel動的制御, 自動判定), BeautifulSoup (スクレイピング)
* **Frontend:** JavaScript (動的メニュー行操作)
* **Infrastructure:** Ubuntu 24.04 LTS, .venv (仮想環境), スマホ実機連携

## 現場への導入メリット
* **現場特化型UI/UX:** 店長が迷わず操作できる、視線誘導まで計算されたインターフェース。
* **頑丈な汎用設計:** 項目を書き換えれば勤怠や在庫管理にも転用できる、長く履き込めるデニムのような設計。
* **実機連携:** プライベートIP環境下でのマルチデバイス連携により、PCとスマホをシームレスに活用。

## 開発背景
プログラミング未経験から始めた52時間の集中学習を土台に、現場のロジックを統合。コードを書くだけでなく、READMEの整備や運用を見据えたアウトプットまでを、一つのプロジェクトとして完遂しました。
