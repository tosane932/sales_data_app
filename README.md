# 🍞 Bakery Sales Management System

## 現場の「困った」を、Pythonで「最適解」へ。
33年間の物流・現場キャリアで鍛え上げた泥臭い知恵を、Pythonという「拡声器」を使ってシステム化しました。
流行りの一発芸のようなアプリではなく、工場の在庫管理から勤怠管理まで応用が利く「普遍的で頑丈な道具」をコンセプトに設計しています。

## 🚀 このシステムの強み
- **現場のためのUI/UX:** 店長が迷わず、最短で操作を完了できる視線誘導デザイン。
- **万能の汎用設計:** 項目を書き換えるだけで、どんな業種の在庫・勤怠管理にも転用可能。
- **マルチデバイス・リアルタイム連携:** プライベートIP(192.168.3.67:5000)を介し、スマホ(Xiaomi 15T)からいつでも売上分析が可能。
- **安全なデータ運用:** Excelファイルの自動集計・分析を行い、生の経営データを守り抜く設計。

## 🛠️ 技術スタック
- **Backend:** Python, Flask (Micro-framework)
- **Database/Data:** SQLite3, openpyxl (Excel動的制御)
- **Frontend:** HTML5, CSS3 (Premium Bakery Theme), Jinja2, JavaScript
- **Development:** Ubuntu 24.04 LTS, VS Code, Git/GitHub

## 📈 主要機能
- **自動集計エンジン:** 過去の売上Excelを読み込み、瞬時に期間別ランキングを生成。
- **データ可視化ダッシュボード:** ゴールド・シルバー・ブロンズのランクバッジで売上トレンドを直感的に把握。
- **徹底したバリデーション:** セル保護と入力規則により、現場での誤操作を物理的に防護。

## 💡 開発ストーリー
プログラミング未経験だった私が、52時間の集中学習と現場での「物流ルート最適化ロジック（C案の精神）」を応用し、合計71時間で完成させました。強引に突っ込まず、周囲（システム・環境）と調和し、安全に最短で目的地へ達する——その思考プロセスがこのコードの骨格です。
